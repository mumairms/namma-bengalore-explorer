# Namma Bengaluru - ನಮ್ಮ ಬೆಂಗಳೂರು

An AI-assisted guide that helps residents **find, understand and make the most of Bengaluru**: which civic office handles what, heritage eateries, lakes, markets, culture, nightlife, festivals and the startup scene.

Zero dependencies. Node.js 18+ only.

```bash
node server.js          # http://localhost:3000   (PORT=8080 node server.js to change)
npm test                # API smoke tests
```

## Features
| Area | What it does |
|---|---|
| **Civic Compass** | Describe a problem in plain words -> ranked match among 27 issue types -> the right agency (GBA + 5 corporations, BESCOM, BWSSB, RTO, Traffic Police, KSPCB ...), numbered steps, documents, helpline, escalation tips. Area -> corporation finder. One-click **complaint letter drafter**. |
| **Ask Namma (AI chat)** | Offline intent engine (civic / places / plans / events / Kannada phrases) over a BM25-style search index. Set `ANTHROPIC_API_KEY` and replies are generated by Claude, grounded on retrieved local context (optional `ANTHROPIC_MODEL`). Falls back to the local engine automatically. |
| **Explore** | 44 places across 7 categories with stories & insider tips, search with synonyms, budget filter, card and map views (Leaflet/OSM), save favourites. |
| **Day Planner** | Mood + budget + time -> greedy nearest-neighbour route with time-of-day fit (breakfast spots in the morning, pubs at night), traffic-aware travel estimates, map polyline, copy/share. |
| **Events** | Month-by-month festival and event calendar (Karaga, Kadalekai Parishe, flower shows, Tech Summit ...). |
| **Kannada Corner** | Phrasebook with native script, romanisation and text-to-speech, plus a quiz. |
| **Community Tips** | Public tips with upvotes, validation, spam/link blocking and rate limits, persisted to disk. |
| **UX** | Dark mode, mobile bottom-nav, keyboard/ARIA friendly, reduced-motion support, print-friendly letters, installable manifest. |

## Structure
```
server.js          HTTP server + REST API + static files (no framework)
lib/store.js       data loading, area->corporation map, tips persistence
lib/search.js      tokenizer, stemmer, synonyms, TF-IDF scoring
lib/triage.js      civic issue ranking + complaint letter builder
lib/planner.js     itinerary engine
lib/assistant.js   chat: local engine + optional Claude call
data/*.json        agencies, issues, places, events, phrases, tips
public/            SPA (index.html, css/, js/app.js)
test/smoke.js      end-to-end API tests
```

## API
`GET /api/meta · /places?category&q&price · /places/:id · /agencies · /issues/:id · /events?month · /phrases · /search?q · /corporation?area · /tips`
`POST /api/triage {text,area} · /complaint · /plan · /chat {messages} · /tips · /tips/:id/upvote`

## Important - verify the data
Helpline numbers, ward->corporation mapping (indicative), opening hours and festival dates change. The app says so wherever it matters; please check `data/*.json` against official sources (GBA, BESCOM, BWSSB, Parivahan) before public deployment. Add places/issues by editing the JSON - no code changes needed.
